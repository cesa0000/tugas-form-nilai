# Form Nilai Ujian

Tugas: Struktur Kendali dan Form Processing (PHP).

## Fitur
- Form input: Nama, Email, Nilai Ujian
- Validasi input (kosong, format email, rentang nilai 0-100)
- Struktur kendali: nilai > 70 = **Lulus**, selain itu = **Remedial**
- Output ditampilkan di halaman browser

## Cara Menjalankan
1. Letakkan `index.php` di folder `htdocs` (XAMPP) atau jalankan:
   ```
   php -S localhost:8000
   ```
2. Buka `http://localhost:8000` di browser.
